# Changes from proposal

Locked for the Phase 1 release on Oct 6, 2026. The four labels are unchanged.

- **Guidelines and the annotation tool moved earlier.** The proposal planned the guidelines for Milestone 2. Phase 1 requires them now, so guidelines v1.0 and the Potato tool are part of this release. An internal pilot started Oct 5 on the hosted tool (160 timed photos; median 6 seconds).
- **Annotation tool: Potato**, the tool the course recommends, instead of a form we would have built in Streamlit or Gradio. It shows one image at a time, has keyboard shortcuts, records time per item, and writes `annotation_output`. Classmates can use https://bluecart.khurramshafique.com (register once) or a zip pack. Gradio and Streamlit stay on the list for the later deployment phase.
- **Labels unchanged:** `accepted`, `accepted_after_prep`, `not_accepted`, `cannot_determine`, plus an optional reason.
- **Two-step question instead of one four-way choice.** The proposal said the label is a combination, not a lookup: first what the item is, then what state it is in. The tool asks that as Step 1 (blue cart kind / never / can't tell) and Step 2, only for a blue cart kind (ready / needs prep / ruined / can't see enough). The same four labels are computed from the two answers (guidelines Section 2).
- **Decision rules locked in guidelines v1.0.** Judge the main item (Rule 0). An item you can identify that is not on Flint's accepted list is `not_accepted`, not `cannot_determine` (Rule 1b). Every disposable cup, paper or plastic, is `not_accepted` (Rule 1c): the city list names only "Plastic Cups", and the campus program rejects hot and cold beverage cups. A rigid plastic takeout clamshell counts as a plastic container (blue cart kind, then Step 2 for food left inside). A foam clamshell is Styrofoam, so it is never the blue cart (Rule 1d).
- **Dataset size.** The proposal aimed for about 1,200 images, mostly photographed by the team. This release has **617**: 77 team photos (Ian Slackta, Sep 28–29, 2026) and 540 sourced images added Oct 4. Daud, Hina, and Khurram have not added their own phone photos yet. Collection can continue after Phase 1.
- **Annotation design.** A 30-photo agreement set is labeled by every annotator. Every other photo is labeled by 2 people. Each person gets those 30 plus the next 170 that still need a label, 200 photos, about one hour at the rate we are planning for a first-time annotator (about 200 photos per hour; our own median was 6 seconds). See README §6.
- **Two new image sources.** The proposal named Wikimedia Commons, Openverse, and Open Images. This release uses 20 Wikimedia Commons photos, 360 RealWaste images, and 160 Kaggle Drinking Waste images. Openverse and Open Images were not used. We use the photos only, not the datasets' material labels. RealWaste is CC BY-NC-SA 4.0, which the proposal had excluded, so the dataset license is CC BY-NC-SA 4.0 (see `LICENSE.md`). Team photos are 77 of 617 (12%), not the planned 65%.
- **Manifest.** Added `category_set`, `item_group_id` (the same object in several states stays in one split), and `sha1` (duplicate detection).
