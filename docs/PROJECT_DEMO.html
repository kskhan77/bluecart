1The project in simple words

One question: does this item go in Flint's blue recycling cart?

  1. We take photos of everyday items: bottles, boxes, cups, cables, bags.
  2. People look at each photo and answer two small questions about it. These people are called annotators. They are our classmates and us.
  3. From their answers we get one label per photo, for example "accepted" or "not accepted".
  4. Later, a computer model learns from the photos and labels, so it can answer the question for a new photo.

Phase 1a is the first half of this: collect the photos, write the rules for the annotators, build the tool they will use, and present it in class.

The rules come from the City of Flint and its waste company, Priority Waste. They are special: for example, Flint takes foil trays and empty aerosol cans, but it does not take plastic cups. That is why annotators must follow our written rules and not what they do at home.

4The tool, step by step

Start: two ways to open the tool

The shared link (what the team uses now)Open bluecart.khurramshafique.com, choose Register, pick a username and a password. Nothing to install and nothing to send back: the tool runs on Khurram's computer and the link reaches it through a Cloudflare tunnel. Everyone gets the same 30 photos first, then the next 170 that still need a label, 200 in total. Every photo is labeled by 2 people.
Your own copy (the zip pack)Unzip the pack, run potato start config.yaml -p 8000, open http://localhost:8000 in Chrome and type your uniqname. No password. If you come back later with the same name, you continue where you stopped. At the end you zip the annotation_output folder and send it to us.

The first time, a welcome page explains the task and the two steps on one screen. It also lists Group 2, the instructor and the teaching assistant. Press Start labeling to continue. You can read it again any time: round ? button, then How it works.

What you see

The photo is on the left. On the right, from top to bottom: the rules box, a status line, Step 1, Step 2 and an optional reason. The status line always says what to do next, and after you answer it shows what your two answers mean. Under the questions is the key legend, and at the bottom right the round help button.

Step 1: what KIND of item is it?

Blue bin · key 1It is a kind of item Flint recycles: paper, cardboard, cans, foil trays, plastic bottles, jugs, tubs, glass bottles, jars.
Black bin · key 2It is a kind Flint never takes in the blue cart: bags, cups, styrofoam, food, batteries, electronics, cords, and anything else not on the blue list.
Question mark · key 3You can't tell what the item is: blurry, cut off, or no single main item.

In Step 1 you only think about the kind of item, not whether it is clean. A pizza box is cardboard, so it is a blue bin kind, even if it is greasy.

Step 2: what STATE is it in? (only after the blue bin)

Ready · key 4Empty, clean, loose, flat. It can go in the blue cart now.
Needs prep first · key 5One quick fix first: rinse it, empty it, flatten the box, or take it out of the plastic bag.
Ruined · key 6Grease or food has soaked into paper or cardboard. Example: a greasy pizza box. It goes in the trash.
Can't see enough · key 7The photo does not show the state, for example you can't see inside the container.

5From two answers to one label

The annotator never picks the final label. The computer makes it from the two answers. These four labels are the same four as in our proposal.

Step 1Step 2Final labelExample
Blue binReadyacceptedClean, flat cardboard box
Blue binNeeds prep firstaccepted_after_prepJar with sauce still inside
Blue binRuinednot_acceptedGreasy pizza box
Blue binCan't see enoughcannot_determineClosed container, can't see if it is empty
Black bin(not asked)not_acceptedCharging cable, plastic bag, coffee cup
Question mark(not asked)cannot_determineBlurry photo

Why two steps? The proposal says the label "is a combination, not a lookup": first what the item is, then what state it is in. Two easy questions are simpler for a person than one hard four-way choice. It also lets us see where people disagree: about the kind of item, or about its state.

6Where the answers go and how to see them

Every click is saved automatically in a folder called annotation_output, one sub-folder per annotator. For the shared link that folder is on Khurram's computer (deploy/local_server/annotation_output), so nobody has to send anything. For a zip pack it is next to the tool, and the annotator zips it and sends it to us.

Way 1: in the browser (the admin dashboard)

Open https://bluecart.khurramshafique.com/admin (shared link) or http://localhost:8000/admin (own copy). It asks for an admin key. The key is not a password anyone chose: the tool writes it into a file called admin_api_key.txt the first time anyone opens the admin page, in the folder the tool was started from.

Key for the shared linkIn Ubuntu, from the project folder:
cat deploy/local_server/admin_api_key.txt
Copy the long text it prints and paste it into the admin page.
Key for your own copyIn the folder where you ran potato start:
cat admin_api_key.txt
On Windows, open the file in Notepad instead. Each copy of the tool has its own key.

After the key, the Instances tab shows each photo, how many people answered it, the most frequent answer and a disagreement score. The Questions tab shows how often each answer was used. The Annotators tab shows how many photos each person has labeled.

Way 2: one page with all labeled photos

cd ~/workspace-school/bluecart/blue-cart-check
.venv/bin/python scripts/show_labels.py --returned deploy/local_server        # the shared link
.venv/bin/python scripts/show_labels.py --returned annotation/packs/internal_01 # a pack

It prints a table and makes labels_review.html. A red border means two people gave different labels. Those are the photos the team should talk about. labeling_time.py gives the seconds per photo from the same files.
